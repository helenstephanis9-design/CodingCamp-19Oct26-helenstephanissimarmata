## 📋 Overview

A fully responsive **personal productivity dashboard** built with pure HTML, CSS, and vanilla JavaScript.  
No frameworks. No libraries. Just clean, modern web standards.

---

## ✨ Features

| Feature                     | Description                                               |
| --------------------------- | --------------------------------------------------------- |
| 🕐 Live Clock               | Real-time HH:MM:SS digital clock                          |
| 📅 Date Display             | Full date with day of the week                            |
| 👋 Time-based Greeting      | Changes between Morning / Afternoon / Evening / Night     |
| 🏷️ Custom Name              | Enter your name in the header for a personalised greeting |
| ⏱️ Focus Timer              | 25-minute Pomodoro timer with animated SVG ring           |
| ▶ Start / ⏸ Stop / 🔄 Reset | Full timer controls                                       |
| ✅ To-Do List               | Add, edit (inline), complete, and delete tasks            |
| 🚫 Duplicate Prevention     | Tasks with the same name (case-insensitive) are rejected  |
| 💾 Local Storage            | Tasks and links persist across page reloads               |
| 🔗 Quick Links              | Add/delete custom bookmark chips                          |
| 🌙 Light / Dark Mode        | Toggle with one click, preference saved                   |
